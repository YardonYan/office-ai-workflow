# 变体

七步是完整版。手上的任务往往只用其中几步，或者顺序要调。这一册给几种改好的版本，直接对号入座。

---

## 变体一：三步精简版

**什么时候用**：材料已经齐了，只是要变成汇报。资料不用查，流程不用画。

```
读文件 → 做表格 → 写汇报
```

| 步 | 简化到什么程度 |
|---|---|
| 读文件 | 只提数据点和待办，不写完整清单 |
| 做表格 | 只做一张核心表，不做多维交叉 |
| 写汇报 | 复用上次的页面骨架，只换内容 |

**省掉的**：查资料、理流程。**不能省的**：口径锁定、数据复核。

---

## 变体二：周报专线

**什么时候用**：每周固定产出，节奏比完整度重要。

```
读文件（本周记录）→ 做表格（进度统计）→ 写汇报（三段式）
```

固定三段：本周进展、风险与阻塞、下周计划。

快速产的三个做法：

1. **平时就记。** 每天下班前写三行流水账，周五拼装，不要周五回忆。
2. **固定口径。** 完成率怎么算、跨周任务算哪周，定一次用一年。
3. **固定骨架。** 页面结构不变，只换内容。读者看三次就形成预期，第四次开始省力。

一句话模板：

> 把本周的记录整理成周报，三段：进展（三条，每条带结果和数据）、风险（含应对）、下周计划。不超过 400 字。

---

## 变体三：月度复盘专线

**什么时候用**：月末、季末，要回溯一段时间并给出下阶段安排。

七步全走，但重心在第 4、5 步。

| 步 | 这个场景的侧重 |
|---|---|
| 查资料 | 只查本月变化，不要历史全景 |
| 读文件 | 重点提「没做成」的事和原因，不只提成绩 |
| 理流程 | 画的是本月实际怎么走的，不是应该怎么走 |
| 做表格 | 至少三个维度：完成情况、时间分布、问题分类 |
| 写汇报 | 问题页要占一页以上，且每条带应对 |

复盘和总结的区别：总结说做了什么，复盘说为什么成、为什么没成。前者是记录，后者是资产。

## 变体四：会议专线

**什么时候用**：开完会要落地，最怕开完就散。

```
读文件（纪要）→ 提行动 → 建跟踪表 → 下次会前复盘
```

关键动作只有三个：

1. **会上或会后两小时内**，把纪要转成行动清单，每条有负责人和时间。
2. **当天发出去**，隔天发等于没发。
3. **下次开会第一件事**，过一遍上次的行动项，完成的销掉，没完成的问原因。

一句话模板：

> 把这份会议纪要转成行动清单，每条含事项、负责人、截止时间、原文依据。负责人没写明的标「待指定」，不要猜。会后直接发群里。

---

## 变体五：竞品或行业简报

**什么时候用**：要给决策层一份短平快的信息稿。

```
查资料 → 写简报（一步出）
```

只有两步，但要求更严：

- 三到五条，多了没人看
- 每条带来源和时间
- 每条要说「对我们意味着什么」，不能只报事实
- 结尾给一个建议动作，哪怕只是「建议继续观察」

一句话模板：

> 围绕 X 主题整理最近两周的信息，三条以内。每条给：信息点、来源、对我们的影响。最后给一句建议动作。

---

## 变体六：纯对话版

**什么时候用**：手上没有文件系统，或者只是临时问一下。

不落盘，全部在对话里完成。代价是断了就没了，所以只用于一次性的小任务。

做法：把七步压成一条提示，明确让它分段输出。

> 分五段帮我做：先给信息简报，等我确认；再给行动清单；再画流程；再做统计；最后出汇报大纲。每段结束停下来等我。

分段输出的好处是能中途纠偏，坏处是要盯着。适合重要但一次性的任务。

---

## 怎么选

| 你的情况 | 用哪个 |
|---|---|
| 材料齐了只差成稿 | 三步精简 |
| 每周固定交 | 周报专线 |
| 月末季末回溯 | 月度复盘 |
| 刚开完会 | 会议专线 |
| 给领导看外部信息 | 竞品简报 |
| 没有文件系统 | 纯对话版 |

选不准就从完整七步开始，跑一遍之后把没用上的步骤删掉，剩下的就是适合你的变体。
