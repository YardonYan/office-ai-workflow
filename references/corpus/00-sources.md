# 语料来源与核验说明

语料的可信度取决于能不能查到出处。这一份把每个文件的来源、哪些是通用方法论、哪些是自写，全列出来。

## 一、按文件分

| 文件 | 来源性质 | 具体说明 |
|---|---|---|
| `01-formats.md` | 通用方法论归纳 | 六种文档的段落结构，来自公开的写作方法论与多篇公开文章的共同做法。结构本身是行业共识，不属任何个人独创 |
| `02-phrases.md` | 通用写法归纳 | 措辞分类、禁用词、强弱替换，来自公开写作规范与本人写作实践。例句全部自写 |
| `03-samples.md` | 全部自写 | 六篇范文由本仓撰写，数据为示意值，不对应任何真实企业与个人 |
| `04-real/` | 使用者提供 | 真实产出，每份自带来源、时间与脱敏说明 |

## 二、方法论出处

这几种方法都不是新东西，出处是公开的，可以自行核验。

| 方法 | 出处 | 说明 |
|---|---|---|
| GRAI 复盘 | 联想集团复盘方法论 | Goal / Result / Analysis / Insight 四步，国内企业培训中广泛使用 |
| KPT | 日本敏捷实践中的回顾方法 | Keep / Problem / Try，适合短周期迭代复盘 |
| AAR | 美国陆军 After Action Review | 预期、实际、差异、改进四问，用于行动后快速复盘 |
| 金字塔原理 | Barbara Minto，《The Minto Pyramid Principle》 | 结论先行、以上统下、归类分组、逻辑递进 |
| 5W2H | 通用质量管理工具 | What / Why / Who / When / Where / How / How much |
| 四段式汇报 | 通用职场写作共识 | 进展 / 成果 / 问题 / 计划，多来源一致 |

这几样属于公共知识，任何人都能用，不存在授权问题。

## 四、没做的事

- 没有复制任何一篇文章的原文段落
- 没有使用带版权的模板文件、图表或语料包
- 范文里的公司、人名、数字均为虚构，不指向真实主体

## 五、怎么判断一条语料可不可信

用的人也需要这套判断，不只是给作者看。

| 判断项 | 可信的表现 | 可疑的表现 |
|---|---|---|
| 有出处 | 能指到具体方法论或公开文件 | 只说「业内公认」 |
| 有边界 | 写明什么情况下不适用 | 什么场景都说好 |
| 有数据口径 | 数字说清怎么算的 | 只给结论数字 |
| 有反面 | 列了常见错误 | 通篇只讲优点 |
| 时间明确 | 标注了写作或检索时间 | 没有日期，不知新旧 |

这五条对任何一份模板都适用，包括本仓的。
