# 语料来源与核验说明

语料的可信度取决于能不能查到出处。这一份说明每个文件的性质、方法归属，以及哪些是自写。

## 一、按文件分

| 文件 | 来源性质 | 具体说明 |
|---|---|---|
| `01-formats.md` | 通用方法论归纳 | 六种文档的段落结构，属于行业通行的写作框架，不属任何个人独创 |
| `02-phrases.md` | 通用写法归纳 | 措辞分类、禁用词、强弱替换，来自公开写作规范与本仓写作实践。例句全部自写 |
| `03-samples.md` | 全部自写 | 六篇范文由本仓撰写，数据为示意值，不对应任何真实企业与个人 |
| `04-real/` | 使用者提供 | 真实产出，每份自带来源、时间与脱敏说明 |

## 二、方法归属

这几种方法都是公共领域的成熟框架，可以自行核验。

| 方法 | 领域归属 | 说明 |
|---|---|---|
| GRAI 复盘 | 企业复盘方法论 | Goal / Result / Analysis / Insight 四步，国内企业培训中广泛使用 |
| KPT | 敏捷开发中的回顾方法 | Keep / Problem / Try，适合短周期迭代 |
| AAR | 军事领域的行动后复盘 | 预期、实际、差异、改进四问 |
| 金字塔原理 | 结构化表达 | 结论先行、以上统下、归类分组、逻辑递进 |
| 5W2H | 质量管理 | What / Why / Who / When / Where / How / How much |
| 四段式汇报 | 职场写作通行做法 | 进展 / 成果 / 问题 / 计划 |

这些属于公共知识，任何人可用，不存在授权问题。

## 三、写作原则

本仓语料遵循三条：

1. 只取结构与通用句式，不取任何成文段落
2. 范文中的数据、公司、人名全部虚构
3. 引用的方法只写方法名与领域，不指名具体作者或出处文章

## 四、怎么判断一条语料可不可信

用的人也需要这套判断，不只是给作者看。

| 判断项 | 可信的表现 | 可疑的表现 |
|---|---|---|
| 有出处 | 能指到具体方法论或公开框架 | 只说「业内公认」 |
| 有边界 | 写明什么情况下不适用 | 什么场景都说好 |
| 有数据口径 | 数字说清怎么算的 | 只给结论数字 |
| 有反面 | 列了常见错误 | 通篇只讲优点 |
| 时间明确 | 标注了写作时间 | 没有日期，不知新旧 |

这五条对任何一份模板都适用，包括本仓的。
