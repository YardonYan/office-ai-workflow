# 措辞库

按文档里的位置分类。写的时候照着找，比临时想快。

---

## 一、开场句

第一句决定对方要不要往下读。

| 场景 | 写 |
|---|---|
| 常规周报 | 本周完成 X 项，其中 A 已交付，B 卡在接口 |
| 报坏消息 | 有一件事需要先同步：X 会晚两天，原因是 Y |
| 请求决策 | 需要您在 A 和 B 之间定一个，周三前定的话能按原计划走 |
| 同步信息 | 同步一件事，不需要您做什么，有变化我再报 |
| 催办 | 这条卡在我这里，今天能给个大概就行 |

不要以「关于……」「为进一步……」开头。那是公文体，不是汇报。

---

## 二、进展表述

动词决定这句话有多少信息量。

| 弱 | 强 | 差别 |
|---|---|---|
| 推进了 | 完成了 A，B 到 80% | 有颗粒度 |
| 跟进了 | 和对方确认了口径，等他们周三给数 | 有动作、有对象、有时间 |
| 处理了 | 改了查询条件，重跑后数字对上 | 有具体改动 |
| 优化了 | 把三步合成一步，每次少点两次 | 有量化 |
| 在做了 | 已完成 A，在做 B，C 还没开始 | 分段 |

常见弱词：推进、跟进、处理、优化、协调、对接、落实。这些词本身没错，但单独用等于没说。后面必须跟宾语和结果。

---

## 三、成果量化

三种量化角度，按手上有哪种用哪种。

| 角度 | 句式 |
|---|---|
| 数量 | 完成 18 项，原计划 20 项，达成 90% |
| 时间 | 原需两天，实际一天半，提前半天 |
| 比例 | 返工率从 39% 降到 12% |
| 范围 | 覆盖 5 个部门、30 人 |
| 对比 | 比上月多 6 项，比目标少 2 项 |

没有数字时的替代写法：给事实，不给形容词。

```
弱：客户反馈很好
强：三家客户主动问能不能续签，两家提到交付速度
```

---

## 四、问题陈述

问题段最容易写成抱怨。三个处理手法：

**手法一：把「谁的问题」改成「什么事卡住」。**

```
弱：信息部不配合，接口一直不给
强：接口文档还没到，联调排期压到下周
```

**手法二：带一个已经做了的动作。**

```
弱：客户需求变来变去，没法做
强：客户三次改需求，已加一道书面确认，本周起执行
```

**手法三：落到可控范围。**

```
弱：市场环境不好，完不成
强：本月询盘量比预期少三成，已把资源转到老客户复购
```

## 五、计划表述

承诺分三档，按确定程度选。

| 确定程度 | 写法 | 什么时候用 |
|---|---|---|
| 确定 | 周五前交付，已验证可行 | 有把握 |
| 较确定 | 计划周五交付，取决于对方周三给数 | 有前提条件 |
| 不确定 | 目标是周五，如果 X 不成立会顺延，我会提前一天说 | 变量多 |

不确定也要给时间点。只写「尽快」「看情况」，等于没承诺。

## 六、请求与协调

| 场景 | 写 |
|---|---|
| 要数据 | 需要业务部出一份 10 月客户反馈原始表，30 号前 |
| 要决策 | 需要您定走 A 还是 B，我倾向 A，理由是成本低 |
| 要人 | 这件事需要再加一个人两周，否则月底这版要砍掉 C |
| 要时间 | 需要多三天，用来补测，不加的话上线风险偏高 |
| 跨部门 | 我理解您那边也忙，我先按去年的口径做一版，您有空扫一眼 |

共同点：说清要什么、什么时候要、不给会怎样。

---

## 七、拒绝与边界

不拒事，拒时间或范围。

```
这周排满了，如果要做这件，B 得往后挪，您定优先级。
```

```
这个可以做，但不在本期范围。急着要的话，先做简化版。
```

```
这部分不在我职责内，我可以帮您对接，但决策要 X 那边定。
```

---

## 八、收尾句

每份文档都要收在一个具体动作上。

| 场景 | 收尾 |
|---|---|
| 周报 | 下周重点是 B 联调，周三前出结果 |
| 月报 | 下月先解决改稿流程，其余按原计划推 |
| 纪要 | 下次会议先过这张表，完成的销掉 |
| 邮件 | 麻烦周三前回复，过了这个点排期要顺延 |
| 方案 | 需要您定预算口径，定了我出执行版 |
| 复盘 | 三个动作项下月复盘时逐条对 |

---

## 九、禁用词

| 词 | 为什么禁 | 换成 |
|---|---|---|
| 大力、全力、切实、深入 | 没有信息量 | 具体动作 |
| 高度重视、圆满完成 | 套话 | 说结果 |
| 基本上、大概、差不多 | 不可靠 | 给数字或给区间 |
| 尽快、尽早 | 没有时点 | 周四前 |
| 有关、相关 | 含糊 | 说清是哪个 |
| 进一步、持续 | 空转 | 说下一步做什么 |

## 十、弱表达换强表达

| 弱 | 强 |
|---|---|
| 报告写完了 | 报告已完成，三页，数据全部对过统计表 |
| 会尽快处理 | 今天下班前给结论 |
| 有些问题 | 两处卡点：接口文档、客户确认 |
| 效果不错 | 完成率 60%，比上月高 15 个百分点 |
| 需要各部门配合 | 需要业务部出一个人对接场景 |
| 领导很重视 | 领导要求本周五前看到第一版 |
| 我觉得可以 | 我建议走 A，成本低三成，风险在 B 那边 |
| 后续继续跟进 | 下周三前出第二版 |

---

## 十一、数字与日期

| 项 | 规范 |
|---|---|
| 金额 | 写具体数字，加单位。不要写「若干」「一部分」 |
| 百分比 | 写清基数。「提升 15%」要说清相对什么 |
| 日期 | 写 11-05 或 11 月 5 日，不写「下周」「月底」 |
| 时间范围 | 写 10-01 至 10-31，不写「这个月」 |
| 数量级 | 超过万用「万」，超过亿用「亿」，不要写一长串零 |

一个细节：同一份材料里，日期格式只用一种。混用会让人觉得不严谨。
