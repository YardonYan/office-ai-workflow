# 第五步 · 写汇报 → 大纲

材料都在手上，难点变成「先说什么、后说什么」。

## 什么时候用

要给上级或客户交一份汇报，手里已经有简报、清单和统计结果。

## 输入

| 字段 | 必填 | 默认 | 什么算坏输入 |
|---|---|---|---|
| `{材料}` | 是 | — | 只有零散截图，没有结论 |
| `{汇报对象}` | 是 | 直属上级 | 不写对象，深度一定错 |
| `{时长}` | 否 | 十分钟 | 五分钟和三十分钟，页数差一倍 |
| `{核心结论}` | 否 | 由 AI 提炼 | 如果你自己也说不清结论，先别看排版 |

## 提示词

```
基于我给的材料，整理一份汇报大纲。

对象：{汇报对象}
时长：{时长}
我希望对方听完之后：{希望对方做什么}

要求：
1. 先给我一句话结论，我确认后你再展开。
2. 每页标题写成结论句，不要写「工作进展」这类主题词。
3. 一页只放一个观点，最多三个要点。
4. 所有数字必须来自材料，不许重算，不许四舍五入成好看的数字。
5. 问题页必须有对应措施，不能只列问题。

输出五页骨架：目标、进展、数据、问题、下月。
如果时长超过二十分钟，再加一页风险与应对。
```

## 输出契约

```
P1 目标：一句话说清这次要解决什么
P2 进展：做了什么，两三句
P3 数据：关键数字，标注来源
P4 问题：卡点 + 已有应对
P5 下月：下一步动作与时间
```

## 验收

- [ ] 每页只有一个结论
- [ ] 标题是结论句
- [ ] 数字与统计表一致
- [ ] 有问题页且带措施
- [ ] 最后一页有明确的下一步

## 失败处理

材料撑不起结论，两条路：缩小结论范围，或者退回补材料。不要靠措辞把弱证据说成强结论。

## 一句话

汇报不是把知道的都说一遍，是让听的人做对决定。跟结论无关的，再好看也删。
