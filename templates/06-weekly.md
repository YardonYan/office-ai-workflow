# 变体 · 周报专线

每周固定交，节奏比完整度重要。这份模板只走三步：读记录、理数据、写三段。

## 什么时候用

每周固定要交周报，手上是散落在聊天、文档、脑子里的零散记录。

## 省掉的两步

查资料、理流程图暂时用不上。但口径锁定和数字复核一步都不能省。

## 平时怎么记

不要周五回忆。每天下班前写三行流水账，五分钟的事：

```
10-28 完成 A 模块联调；B 卡在接口文档；明天推 C
```

三行，不用工整。周五把五行这样的流水账丢给 AI。

## 周五的提示词

```
把本周的流水账整理成周报。

格式：
【本周进展】三条，每条含结果和数字
【风险与阻塞】有就写，含已有应对；没有就写「暂无」
【下周计划】三条，带时间点

要求：
1. 每条进展要有可验证的结果，不要写「推进了」「跟进了」
2. 不超过 400 字
3. 语气客观，不用「圆满完成」「高度重视」这类词
4. 如果某条流水账我看不出结果，直接问我，不要编
```

## 输出契约

```
【本周进展】
- 完成 A 模块联调，自测通过（原计划周四，实际周三）
- B 完成 80%，卡在对方接口文档
- C 已排期，下周启动

【风险与阻塞】
- 接口文档未给全，已启用备用方案，影响可控

【下周计划】
- 周三前完成 B 联调
- 周五前压测
```

## 验收

- [ ] 每条进展有结果或数字
- [ ] 没有形容词堆砌
- [ ] 风险不藏，且带应对
- [ ] 400 字以内

## 三条长期习惯

1. **固定骨架**。三段不变，读者看三次就形成预期，第四次开始省力。
2. **固定口径**。完成率怎么算、跨周任务算哪周，定一次用一年。
3. **当天写完当天发**。周五下午写的周报，周一发出去，价值减半。

## 一个反例

> 本周在领导的正确指导下，团队齐心协力，圆满完成了各项任务，取得了显著成效。

这句话里没有一个可核实的事实。写成这样，等于没写。
