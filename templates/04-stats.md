# 第四步 · 做表格 → 统计表

这一步最容易出错。错不在算，在口径没定就先算。

## 什么时候用

手上有台账、导出表或原始 Excel，要变成能放进汇报的统计结果。

## 输入

| 字段 | 必填 | 默认 | 什么算坏输入 |
|---|---|---|---|
| `{数据}` | 是 | — | 已经汇总过的表，看不出原始明细 |
| `{统计维度}` | 是 | 按状态 | 维度超过三个，先砍到两个 |
| `{口径定义}` | 否 | 见下 | 口径没写清的，先让 AI 列出待确认项 |

## 提示词

```
基于我提供的表格做统计，先定口径，再算数。

第一步：列出你打算用的口径，逐条问我确认，不要直接开始算。
需要确认的至少包括：
- 什么叫「已完成」
- 跨月任务算在哪个月
- 空值怎么处理（不要默认当 0）

第二步：我确认后，按以下要求输出：
1. 一张统计表：分类 | 数量 | 占比
2. 表格下方写清公式，例如：完成率 = 已完成 ÷ 总数 = 18 ÷ 30 = 60%
3. 单独列一行「未填 N 条」，不计入分母
4. 分类加起来必须等于总数，不等于就停下来说明差在哪

不要做图。我要先看数对不对。
```

## 输出契约

- 一张表 + 一行公式 + 一行缺数说明
- 分类合计等于总数，或明确说明差异来源
- 没有出现「约」「大概」这类词

## 验收

- [ ] 口径写下来了，不是我脑子里的
- [ ] 空值单列，没被当 0
- [ ] 公式能复算，结果对得上
- [ ] 分类加起来等于总数

## 失败处理

数据自相矛盾（同一任务两种状态），不要自己选一个。列出来，标冲突，请业务方判定。

## 提示

先要数，再要图。数的口径错了，图越漂亮错得越远。
