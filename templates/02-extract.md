# 第二步 · 读文件 → 行动清单

长文档读完没结果是常态。这个模板要的是能直接派活的清单，不是摘要。

## 什么时候用

手上有会议纪要、制度通知、复盘报告或长 PDF，需要从中拿出「谁、在什么时候、做什么」。

## 输入

| 字段 | 必填 | 默认 | 什么算坏输入 |
|---|---|---|---|
| `{文件}` | 是 | — | 扫描件、加密文件，先要可复制的版本 |
| `{阅读目的}` | 是 | — | 写「了解一下」等于没定目的 |
| `{已有背景}` | 否 | 无 | 上一步的简报，用来圈定读哪几段 |

## 提示词

```
读我提供的文件，按五要素提取，不要写摘要。

五要素：关键结论、待办事项、负责人、截止时间、原文依据。

规则：
1. 只要行动，不要观点。写「周三前出接口文档」，不要写「会议强调了接口的重要性」。
2. 负责人和时间只写文件里明确写了的。没写的填「原文未指定」，不要根据上下文推测。
3. 一段话里有多个待办，拆成多条，不要合并成一条。
4. 每条注明来自哪一段，方便我回去核对。

输出表格：
事项 | 负责人 | 时间 | 依据

表格下面单独一行：文件里没有明确负责人或时间的条目共 N 条，需要补充。
```

## 输出契约

- 四列表格，事项是动词开头
- 「原文未指定」出现的地方要汇总成一行
- 每条能定位到原文段落

## 验收

- [ ] 每条都能回到原文
- [ ] 没有凭空补出来的负责人和时间
- [ ] 待办是动作，不是状态
- [ ] 背景描述没有被误当成待办

## 失败处理

文件读不出内容，直接说读不了，请对方给可复制版本。不要根据文件名猜内容。

## 常见变形

- **只要数字不要待办**：把五要素换成「指标、数值、时间、口径、出处」，用于从报表里提数。
- **只要风险不要待办**：换成「风险点、触发条件、影响范围、已有应对」，用于风险梳理。
