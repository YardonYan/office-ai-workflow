# 第一步 · 查资料 → 一页简报

复制提示词，替换三个占位符，直接发。

## 什么时候用

要先知道某件事发生了什么变化，再决定下一步。要的是能拿去做判断的简报，不是一堆链接。

## 输入

| 字段 | 必填 | 默认 | 什么算坏输入 |
|---|---|---|---|
| `{主题}` | 是 | — | 太宽，比如「行业动态」。收窄到一个具体问题 |
| `{时间范围}` | 是 | 最近 7 天 | 一个季度以上的范围，对周决策没用 |
| `{关注点}` | 否 | 全部 | 超过三个关注点，说明还没想清重点 |

## 提示词

```
你在为一位要拿这份材料做判断的人准备一页简报。

主题：{主题}
时间范围：{时间范围}
关注点：{关注点}

规则：
1. 最多四条。超过四条说明主题还没收窄，先帮我收窄。
2. 每条必须有我能打开核对的来源：文件名、链接或通知编号。
   写「网上」「内部讨论」不算来源。
3. 每条标日期。过期信息要标明过期。
4. 每条写一句「这对我们的工作意味着什么」。
   只有事实没有影响判断的，不要放进来。

输出一张三列表格：
信息点 | 来源 | 对我们的影响

表格下面写一句话：我接下来最该做的一件事。
```

## 输出契约

- 三列，最多四行
- 每行都能点回来源
- 结尾那句是动作，不是话题

## 验收

- [ ] 每条来源我都能打开
- [ ] 没有超出时间范围的内容，或已标注
- [ ] 每行都有影响判断，不只是事实
- [ ] 换个人拿到也能看懂，不用我解释

## 失败处理

查不到可用的东西，就回一句：查了什么范围、没查到什么、哪个人或哪份文件可能有。不要用听起来合理的内容填空。
